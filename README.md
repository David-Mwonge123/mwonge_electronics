# MWONGE ELECTRONICS

## Design System
Colors: --bg #111111, --card #1a1a1a, --text #fff, --muted #a1a1aa, --accent #3b82f6
Typography: Inter, H1 900, H2 1.1rem 700, meta 0.8rem, labels 0.7rem uppercase
Spacing: base 4px, radius 20px cards, 999px pills

## CSS Structure
Tailwind CDN for layout/grid/flex/responsive + custom properties for theming.
Glass class as secondary theme. .card, .card-body.

## Browser Compatibility Report
- CSS Grid: supported
- backdrop-filter: -webkit- prefix added for Safari
- modal/cart: works all browsers


## Features
7 products, grid hover lift, 7 modals, static cart sidebar, filter/sort UI only, print stylesheet, dark mode via prefers-color-scheme, custom properties.
